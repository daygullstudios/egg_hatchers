## Image source records

- `assets/images/ui/app_logo.png` and the platform branding source derive from
  `assets/branding/nestarium_source.png`. The prompt and generation record live
  in `assets/branding/README.md`.
- Classic animal, boss, egg, projectile and UI gameplay art is either
  in-repository procedural art, AI-assisted art made for this project, or a
  repo-generated derivative from that project art.
- Retro Pixel animal and egg art is project-specific generated pixel artwork
  built from the Nestarium catalog and retro style rules.
- Realistic animals, eggs and boss backgrounds are project-specific generated
  artwork made for Nestarium.
- Ultimate Nest head art is project-specific generated artwork in Classic,
  Retro Pixel and Realistic styles.

Release requirement: before public release, keep this file updated whenever a
new external image source is added. Public release should not include
untracked stock art, downloaded images, or screenshots without an entry here.
