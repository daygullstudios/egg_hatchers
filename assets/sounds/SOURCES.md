# External sound sources

The following effects are recordings downloaded from Freesound and released
under Creative Commons Zero (CC0 1.0). Attribution is not required, but the
source details are retained here for provenance.

- `sfx/purchase_real.mp3`: "Cash Register Purchase" by Zott820,
  https://freesound.org/s/209578/ (CC0 1.0). The bundled file is Freesound's
  high-quality preview of the 2.754-second recording.
- `sfx/finisher_slash_real.mp3`: "Woosh 1" by mateusboga,
  https://freesound.org/s/614084/ (CC0 1.0). Recorded weapon swing; the bundled
  file is Freesound's high-quality preview.
- `sfx/egg_crack_recorded.mp3`: "breaking a pencil.wav" by an_na_ba_na_na,
  https://freesound.org/s/486374/ (CC0 1.0). A real pencil breaking with a
  sharp, dry snap; the bundled file is a 0.627-second game edit of Freesound's
  high-quality preview.

All other registered short effects are original procedural Foley generated by
`tools/generate_placeholder_sounds.py`.
